# NexaPOS Lite till - tests

The Lite till (`/lite/`) is a plain-JavaScript till for old iPads (iOS 10). See `LITE-TILL-DESIGN.md`
in the release workspace for the whole plan. These are the checks that keep it safe:

| Command | What it proves |
|---|---|
| `node tests/lite/es5.test.js` | every script of the page parses as strict ES5 and uses no built-ins missing from Safari 10 (the checker is itself tested against arrow functions, `let`, template strings, classes, async) |
| `node tests/lite/core.test.js` | the join / catalog / login logic against a scripted fake server; logins are checked with real bcrypt hashes made by the app's own library (`fixtures/bcrypt_fixtures.json`) |
| `LITE_API=http://127.0.0.1:8080/index.php node tests/lite/integration.js` | the same logic against a REAL platform server: invite, join, catalog with stock summed from movements, login, a used invite refused |

`vendor/acorn.js` (MIT) is only used by the ES5 checker. `lite/bcrypt.min.js` is bcryptjs 2.4.3 (Apache-2.0, plain ES5).

`fixtures/bcrypt_fixtures.json` is generated by `test/tool/make_bcrypt_fixtures.dart` in the mobile repo
(`dart run test/tool/make_bcrypt_fixtures.dart <out.json>`).

To run the integration test locally you need the platform repo's PHP server on a fresh MySQL database
(see the platform repo's `tests/integration/run.php` for the environment variables).
